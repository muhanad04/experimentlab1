# labo

Single-phase transformer experiment walkthrough with live calculations.

## GitHub Pages

Enable **Deploy from a branch → main → / (root)**.

The built website is already at the repository root. No build workflow or dependency installation is required.

- `index.html`, `styles.css` — interface
- `src/` — browser modules
- `docs/` — physics assumptions and experiment coverage
- `.nojekyll` — static Pages deployment

Experiment data stays in memory only. Refresh restarts the experiment. Export results explicitly to keep them.

* These measurements are computed simulations, not physically validated results.
